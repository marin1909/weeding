# 💍 Invitație Interactivă de Nuntă (`weeding`)

Pagină web interactivă pentru invitația de nuntă, optimizată pentru **orice telefon (iOS / Android)** și **laptop/desktop**, pregătită pentru **GitHub Pages**.

## ✨ Funcționalități incluse
- **Plic 3D Interactiv cu Sigiliu de Ceară Aurie**: La deschidere, plicul se deschide animat, scrisoarea iese la lumină, se lansează confetti aurii și pornește o melodie ambientală romantică (sintetizată direct în browser, fără fișiere externe care să se blocheze).
- **Particule de Aur Plutitoare & Efecte Parallax**: Animații fluide pe `<canvas>` la 60fps.
- **Numărătoare Inversă Live** + buton **Salvează în Calendar** (`.ics` compatibil cu iPhone, Android și Outlook).
- **Secțiune Părinți & Nași** cu efect 3D la mișcarea mouse-ului pe laptop.
- **Programul Zilei (Cununia Civilă, Religioasă, Petrecerea)** cu butoane directe către **Google Maps**.
- **Galerie Foto cu Lightbox** + Paletă **Dress Code**.
- **Formular RSVP Interactiv** cu trimitere directă a mesajului completat pe **WhatsApp** către miri.

## 🛠️ Cum modifici numele, data și locațiile
Deschide fișierul [`script.js`](./script.js) și editează obiectul `WEDDING_CONFIG` aflat chiar pe primele linii (liniile 6–51).
